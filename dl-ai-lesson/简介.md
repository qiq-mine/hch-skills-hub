# DL.AI 课程视频制作与端到端发布管线

面向中文学习者的 AI 技术讲解视频及多渠道宣发物料制作全流程（整合原 `deeplearn-vp-create` 与双渲染器规范）：

- **端到端流水线**：外网/本地字幕提取 → 7 场景结构化翻译与分镜 → HTML 故事板审阅门禁 → edge-tts/DashScope 语音合成与混音 → 双引擎渲染 → 成片校验与小红书 3:4 宣发图文卡片。
- **分支 A（默认）**：Python + Pillow + ffmpeg 确定性渲染，可复用场景函数、CLI 驱动。
- **分支 B**：Remotion + React 审阅优先，先出 `review.html` 故事板供用户确认再渲染。
- **多端资产交付**：1080p 视频成片 + 双尺寸封面（16:9 / 4:3）+ 小红书竖版 6 图卡片套件（1080×1440）。
