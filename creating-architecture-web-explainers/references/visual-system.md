# HCH.HUB 视觉系统

## 可复用令牌

| 令牌 | 职责 |
| --- | --- |
| `#05091A` | 深色背景与沉浸式画布 |
| `#E2EEFF` | 高可读性正文与主要标题 |
| `#00CFFF` | 主要交互、连接与信息强调 |
| `#00FF8A` | 成功、健康状态与正向流向 |
| `#FF7C5C` | 风险、告警与关键权衡 |

这些色彩、间距、圆角、边框和动效强度可跨主题复用。具体服务名称、架构节点、指标和例子属于单次主题内容，不能伪装成设计令牌。

## 排版与组件边界

正文桌面端不低于 16px、移动端不低于 16px；标题按层级明显递增，正文行高建议 1.5–1.7。不得用小字号或低对比度伪造科技感。

- **Hero**：说明核心问题、范围和读者收益，不承载完整架构细节。
- **对比卡**：只用于并列方案与清晰取舍，不代替流程。
- **Stage**：用于纵向可连续阅读的单一语义阶段。
- **Slide**：用于四个及以上独立流程阶段；每屏一个阶段并保留操作上下文。
- **总结**：回收结论、限制和下一步，不引入关键新概念。

导航默认 `opacity: .6`，`hover` 和 `focus-visible` 变为 1；焦点轮廓必须可见。

## 交互与验收

桌面端检查内容层级、悬停与键盘焦点；移动端检查单列可读性与至少 44px 的触控目标。Slide 支持方向键和触控滑动，并在首尾禁用不可用按钮。以 `prefers-reduced-motion` 关闭或显著降低非必要动画。

截图验收至少覆盖桌面与移动视口：检查文本是否清晰、对比度是否足够、焦点是否可见、导航是否可操作，以及长标题、密集关系和末页状态是否溢出或被遮挡。
