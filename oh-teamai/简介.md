# oh-teamai: 团队级 AI 资产中台与配置协同治理

源自腾讯开源项目 `teamai-cli`，负责将个人的 AI 习惯转化为团队共享的组织级工程资产：

- **统一全员配置**：在 16+ 款主流 AI 编程工具（Claude Code, Cursor, Windsurf, Antigravity, Roo Code 等）之间实现 Skills、Rules、MCP 的无缝分发与双向同步。
- **团队 Wiki 与经验回流**：自动化逆向大型代码库架构沉淀为组织知识库，支持从单次高质量开发会话中提取经验并回流共享。
- **协同治理工作流**：支持从零初始化组织知识仓库、成员拉取同步更新、以及通过 Git PR/MR 严格审核共享新技能。

与单仓级工程标准 `ai-native-repo` 形成“团队中台 ↔ 项目落地”的完整闭环。
