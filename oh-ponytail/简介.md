# oh-ponytail: 极简代码阶梯法 (Anti-Overengineering)

源自开源项目 `ponytail` 的资深工程师反过度工程与抗代码膨胀思考法则：

- **核心信条**：最好的代码就是你从来没写过的那行代码。
- **7 阶思考梯**：质疑需求必要性 (YAGNI) → 平台原生能力 → 语言标准库 → 复用现有第三方依赖 → 单行优先 → 局部最简 → 停止过度设计。
- **三档执行强度**：支持 `lite`（温和提示）、`full`（默认阶梯强约束）与 `ultra`（极致代码剪枝）。

与 `pstack` 的极简懒惰原则（`principle-laziness-protocol`）形成强力共振。
