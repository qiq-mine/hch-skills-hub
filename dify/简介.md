# Dify 全栈软件工程规范与代码审查套件

Dify 官方全栈生产级软件工程规范与代码审查技能集合，深度适配 Google Antigravity、DeepSeek Harness (DSH) 与 Claude Code。
包含 5 大专业技能：
1. **backend-code-review**：Python/Flask/SQLAlchemy 后端代码审查（分层边界、租户隔离、Repository 抽象、显式事务与并发锁保护）。
2. **frontend-code-review**：React/Next.js/TypeScript 前端审查（无障碍 a11y、设计系统基元、TanStack Query 契约、运行时不变量、重渲染优化）。
3. **how-to-write-component**：React 组件架构设计指南（所有权解耦、状态分层、次级浮层契约、Tailwind v4 标准）。
4. **frontend-testing**：Vitest 与 React Testing Library 行为级测试规范（Behavior over Implementation、选择器优先级、系统边界 Mock）。
5. **e2e-cucumber-playwright**：Cucumber BDD 与 Playwright 端到端自动化测试（声明式 Gherkin、Web-first 断言、高保真无硬等待）。

配套提供完整的本地化规范文档，实行工业级 P0~P3 缺陷分级标准。
