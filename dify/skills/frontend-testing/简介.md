# Dify 前端测试规范 (Frontend Testing)

基于 Vitest 与 React Testing Library (RTL) 的高质量前端测试指南。
推行“测试用户可观察行为而非内部实现”的工程哲学。涵盖无障碍查询选择器优先级（getByRole > getByLabelText > getByText）、基于 `@testing-library/user-event` 的真实交互模拟、系统边界 Mock 纪律（MSW/浏览器 API 隔离）、精准异步等待（waitFor/findBy* 杜绝 sleep）以及低价值测试精简治理。
确保测试用例具备高确定性与强抗重构能力。
