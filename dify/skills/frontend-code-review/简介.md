# Dify 前端代码审查 (Frontend Code Review)

面向 React / Next.js / TypeScript 与 Dify UI/Tailwind CSS 体系的高质量代码审查技能。
涵盖 8 大专业规则包：无障碍访问 (a11y)、设计系统基元契约 (Dify UI / Base UI / Overlays / Forms)、组件架构与状态生命周期、TanStack Query 数据请求与缓存失效、Dify 运行时不变量（Workflow/RAG 渲染隔离）、性能与重渲染优化、回归测试规范及 TypeScript/Tailwind 编码质量。
分级输出 P0~P3 审查结论与精准修复建议。
