# 拼版检查（启发式）

每一项都是启发式：给出结论时必须带置信度（高/中/低）并写出依据。单板 Gerber 与拼版 Gerber 的层表相同，区别只在外形层内容与工艺要素上。

## 1. 外框是否为拼版外框
- **看什么**：外形层（.GM1/.GKO）bbox 的宽高，与单板尺寸对比。
- **高**：bbox 明显大于单板尺寸，且内部有重复的单板轮廓线。
- **中**：只有外框、看不到内部单板轮廓（可能用 V-CUT 分板，无内框线）。
- **低**：只有一个矩形外框且与单板尺寸一致——可能是单板，也可能是 1×1 拼版，无法区分，需拼版说明确认。

## 2. V-CUT
- **看什么**：机械层（.GM3）或外形层里的长直线；直线应横贯整块拼版、与分板线重合。
- **高**：机械层有与拼版分板线重合的长直线，且拼版说明写了 V-CUT。
- **中**：只有直线、没有拼版说明佐证。
- **低**：无机械层、无长直线——可能是邮票孔分板，也可能确实没分板要求。

## 3. 邮票孔（Mouse Bites）
- **看什么**：钻孔文件里沿分板线排列的小孔（常见 0.5mm 左右、间距约 1mm），且外形层在对应位置有断续缺口。
- **高**：小孔沿直线等距排列 + 外形层同位置有缺口。
- **中**：只有小孔排列，无外形缺口佐证。
- **低**：小孔散布、无规律——可能是普通过孔/定位孔。

## 4. 工艺边与定位孔
- **看什么**：外框四周 5mm 左右的空白边；边上直径 3mm 上下的圆孔（工具孔）。
- **高**：外框比单板区大一圈空白边 + 边上有对称分布的大孔。
- **中**：只有空白边或只有孔。
- **低**：无工艺边——可能是板厂自己加边，或出货为单板。

## 5. Mark 点（光学定位点）
- **看什么**：阻焊层或铜层上直径约 1mm 的孤立圆形 flash，位于板角或拼版四角，通常 3 个。
- **高**：3 个 1mm 圆点呈 L 形分布于拼版角上。
- **中**：有圆点但数量/位置不典型。
- **低**：未找到——可能 Mark 点在钢网层或由板厂自定。

## 6. 钻孔与铜层对齐（粗查）
- **看什么**：钻孔 bbox 与铜层 bbox 是否在同一坐标系、尺寸是否接近。
- **高**：两者 bbox 偏差 < 0.1mm。
- **中**：偏差 0.1~0.5mm——可能是坐标原点不同，需核对。
- **低**：偏差 > 0.5mm 或钻孔超出铜层外框——先报异常，不下结论，让板厂或 EDA 复核。

以上都不构成 DRC 结论。任何一项报“低”时，findings 里写“需拼版说明或板厂确认”。
