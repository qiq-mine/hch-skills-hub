# oh-context-mode: 智能体上下文防爆与代码计算范式

源自开源项目 `context-mode`，面向大规模数据、日志和复杂环境交互的 Token 极致优化技能（节省高达 98% 上下文）：

- **核心范式（Think in Code）**：智能体不是数据处理器，而是代码生成器。严禁直接把海量日志、大 JSON 或浏览器全量 DOM dump 到 LLM 上下文。
- **沙箱隔离与中间文件暂存**：通过本地脚本执行、文件暂存与 SQLite FTS5/BM25 全文检索，仅向主上下文返回提炼后的结构化摘要。
- **四大典型场景**：大规模日志排查、超长测试输出、Playwright 页面交互快照优化及大型 API 调试。
