# oh-ruflo: 企业级多智能体协同底座与蜂群编排

源自开源项目 `ruflo`（原 claude-flow），面向超复杂工程系统的多角色协作底座：

- **核心范式（Agent = Model + Harness）**：大模型负责推理思考，Harness 负责提供环境沙箱、314+ MCP 工具连接与跨会话长效记忆。
- **两大核心拓扑**：分层防漂移蜂群（Hierarchical Swarm，主控协调）与去中心化网状蜂群（Mesh Swarm，对等协作）。
- **3 阶模型智能路由**：确定性本地脚本（0成本） → 轻量模型（快速预处理） → 深度推理模型（复杂代码重构与对抗验证）。
