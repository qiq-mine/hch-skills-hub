# oh-marketing-growth: 技术产品营销与增长工程流

源自开源顶流项目 `marketingskills`（50+ 领域专员 SOP），将增长黑客方法论转化为严谨的工程化流转：

- **转化率优化 (CRO)**：落地页系统性诊断、跳出率归因与转化漏斗修复。
- **高转化技术文案**：清晰优于炫技、核心价值主张 (Value Prop)、PAS 与 BAB 经典架构打磨。
- **AI-SEO 与知识引擎优化**：Schema 结构化标记、针对 LLM/Perplexity 的检索可见性优化。
- **开发者产品冷启动 (Launch Playbook)**：爆款 GitHub README 工程化排版规范与 Show HN 发布策略。
